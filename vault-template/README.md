# Campaign vault

An Obsidian vault laid out the way GM AutoPrep's skills expect. Open this folder as a vault in
[Obsidian](https://obsidian.md) (optional — it's plain markdown), fill in `campaign.yaml`, and run
`/gm-setup` in Claude Code from inside it.

| Folder | What lives there |
|---|---|
| `00-Meta/` | The campaign's memory: **Plant-Payoff Ledger**, **Revelation Sequence**, Campaign Brief |
| `01-Sessions/` | Planned sessions; `Recaps/` (what actually happened) and `Prep/` (the prep docs) |
| `02-NPCs/` | One note per NPC — `Major/`, `Minor/`, and `PCs/` |
| `03-Locations/` `04-Factions/` `05-Items and Handouts/` | World notes |
| `06-Arcs/` | One note per arc: goal, sessions, level range |
| `07-GM-Tools/` | Your own reference: pacing, rulings, endings |
| `08-Assets/` | Generated portraits, handouts and maps (kept so you can reuse or re-roll them) |
| `Templates/` | Note templates the skills follow |

**Archivist and the chat log are the record of what happened; this vault is what it means.**
The skills never overwrite your notes — they write recaps and prep docs, update the ledger rows
that moved, and tell you about everything else.
