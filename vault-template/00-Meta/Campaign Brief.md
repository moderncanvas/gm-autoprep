# Campaign Brief

> The one page an assistant (or a co-GM) needs before touching anything. Keep it current —
> the skills read it every run.

## The pitch
*Two or three sentences: what the campaign is about and what makes it yours.*

## The core secret
*What the players don't know yet that everything hinges on. Which reveals must not land early.*

## How it can end
*The endings you'd be happy with. If "never steer" applies, say so here.*

## Load-bearing mechanics
*Custom mechanics, clocks, counts (e.g. "150 stones exist: the villain holds 100, an ally unknowingly holds 50").*

## Table rules
*Tone, lines and veils, consent for recordings, pronouns, anything the assistant must respect.*
